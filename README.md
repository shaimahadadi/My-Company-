# My-Company-

نظام وكلاء ذكاء اصطناعي لإدارة أكاديمية تدريب: مؤسس واحد هو المدير والمدرب، ومدرب ثانٍ، و4 وكلاء.

| الوكيل | الدور |
| --- | --- |
| عبدالله | العمليات |
| سارة | المبيعات وشؤون المتدربين |
| أحمد | التسويق |
| ورد | المحتوى |

## الدورات الحالية

القسم التقني:

- دورة الذكاء الاصطناعي التوليدي
- دورة مايكروسوفت إكسل

الأسعار والمواعيد في `shared/courses.yaml`.

## محتوى المستودع

- `DESIGN-REQUEST.md`: طلب التصميم الكامل
- `agents/`: مجلد لكل وكيل، فيه تعليماته `prompt.md` وإعداداته `config.yaml`
- `shared/courses.yaml`: الدورات والأسعار والمواعيد، المصدر الوحيد الذي يقرأ منه كل الوكلاء
- `shared/escalation-rules.md`: متى يرجع الوكيل للمؤسس
- `workflows/`: سير العمل اليومي والأسبوعي
- `docs/org-chart.md`: الهيكل التنظيمي
